# Сайт дуэта «In stile russo» — инструкция

Эта инструкция написана для человека без опыта в программировании.
Читайте по порядку, ничего страшного здесь нет.

---

## 1. Из чего состоит сайт

| Файл | Что внутри | Нужно ли трогать |
|---|---|---|
| `content.js` | **Все тексты и цены** | Да, это ваш главный файл |
| `index.html` | Каркас страницы | Только один раз, см. раздел 4 |
| `style.css` | Внешний вид | Нет |
| `script.js` | Логика страницы | Нет |
| `img/` | Фотографии | Да, замените файлы на свои |
| `audio/` | Отрывки записей для кнопок «Послушать» | Да, положите три mp3 |
| `favicon/` | Иконка сайта во вкладке браузера | Нет |
| `robots.txt`, `sitemap.xml` | Файлы для поисковиков | Один раз, см. раздел 4 |
| `.htaccess` | Настройки скорости для хостинга | Нет, просто залейте |

## 2. Как поменять текст

1. Откройте `content.js` любым текстовым редактором.
   Подойдёт «Блокнот», но удобнее бесплатный **Notepad++** или **VS Code** —
   они подсвечивают ошибки цветом.
2. Найдите нужную строку. Файл разбит на пронумерованные разделы:
   первый экран, форматы, репертуар, видео, отзывы, о дуэте, контакты.
3. Меняйте **только текст между кавычками**:

   ```js
   title: 'Народная музыка, под которую танцуют, а не вежливо слушают',
   ```

   Правим то, что стоит между `'` и `'`. Сами кавычки и запятую в конце
   не удаляем.
4. Сохраните файл и обновите страницу в браузере (клавиша F5).

### Три правила, чтобы не сломать сайт

- **Не удаляйте** кавычки `'`, запятые `,`, фигурные `{}` и квадратные `[]` скобки.
- Если внутри текста нужны кавычки — ставьте «ёлочки», как в этой строке.
  Обычные `'` внутри текста сломают страницу.
- Меняйте по одному месту за раз и проверяйте в браузере. Так сразу понятно,
  что именно сломалось, если что-то пойдёт не так.

### Если сайт всё-таки сломался (белый экран)

Нажмите `F12`, откройте вкладку **Console** — там красным будет написан
номер строки с ошибкой. Чаще всего это лишняя или пропавшая кавычка.
Верните файл из резервной копии — делайте её перед каждой правкой.

## 3. Что нужно заполнить обязательно

Всё, что записано как `{{ЗАГЛАВНЫМИ_БУКВАМИ_В_ДВОЙНЫХ_СКОБКАХ}}` — это
заглушка. Пока она стоит, посетитель видит её прямо на странице.
Ничего из этого сайт не придумал за вас: неизвестные данные оставлены пустыми,
чтобы на сайте не оказалось выдуманных фактов.

**Быстрая проверка:** откройте сайт, нажмите `F12`, вкладка **Console**.
Скрипт сам напечатает список всего, что осталось незаполненным.

## 4. Что вписать один раз после покупки домена

Адрес сайта нужен в четырёх файлах. Найдите `{{АДРЕС_САЙТА}}` и замените
на адрес **без косой черты в конце**, например `https://instilerusso.ru`:

1. `content.js` — раздел 10;
2. `index.html` — строка `<link rel="canonical" …>` и блок в самом низу шапки;
3. `robots.txt`;
4. `sitemap.xml`.

Заодно в `index.html`, в блоке `application/ld+json` (это данные для Яндекса
и Google), впишите имена музыкантов, телефон, почту и ссылки на соцсети —
там стоят те же заглушки.

**Почему тексты в двух местах.** Заголовок и описание сайта продублированы
в `index.html` вверху файла. Так сделано специально: роботы Telegram
и WhatsApp не запускают скрипты и читают только эти строки. Если меняете
описание в `content.js`, поменяйте и там — это единственное исключение.

## 5. Фото, видео и музыка

### Фотографии

Замените файлы в папке `img/` на свои, **оставив те же имена**:
`hero.webp`, `about.webp`, `photo-1.webp` … `photo-6.webp`.
Сейчас там стоят заглушки с надписью «Замените это фото».

- Формат — **webp**. Обычные `jpg` можно бесплатно перевести в webp
  на сайте squoosh.app: перетащите фото, справа выберите WebP, скачайте.
- Размер: горизонтальные фото примерно 1200×900 точек, вертикальные 900×1200.
- Файл тяжелее 300 КБ лучше сжать — иначе сайт будет медленно открываться.
- В `content.js` рядом с каждым фото есть строка `alt` — короткое описание
  того, что на снимке. Его читают вслух незрячим и учитывают поисковики.
  Опишите фото своими словами: «дуэт играет на свадьбе в зале».

Картинка `img/og.webp` — та, что показывается, когда ссылку кидают
в мессенджер. Её тоже стоит заменить на хорошее фото дуэта.

### Видео с YouTube

Нужен не весь адрес, а **код ролика** — то, что стоит после `v=`:

```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
                                 ↑ вот это
```

Вставьте `dQw4w9WgXcQ` вместо `{{YOUTUBE_ID_ГЛАВНОЕ}}` в `content.js`.

Ролик не подгружается, пока посетитель не нажал на него, — так страница
открывается заметно быстрее. Картинку-превью сайт возьмёт с YouTube сам.

### Звуковые отрывки для кнопок «Послушать»

В блоке «Репертуар» у каждого направления есть кнопка, по которой играет
короткий отрывок. Это самое ценное на сайте музыкантов: организатор слышит
вас, не уходя со страницы.

1. Нарежьте три отрывка по **10–15 секунд** — по одному на направление.
   Подойдёт бесплатный Audacity: открыть запись, выделить кусок,
   «Файл» → «Экспорт» → mp3.
2. Положите файлы в папку `audio/`, назовите понятно:
   `narodnaya.mp3`, `kaver.mp3`, `meshap.mp3`.
3. В `content.js`, раздел 4, впишите путь вместо заглушки:

   ```js
   sample: '{{САМПЛ_1}}'     ->     sample: 'audio/narodnaya.mp3'
   ```

Пока файла нет, кнопка показывается серой и не нажимается.

Как это работает у посетителя: одновременно играет только один отрывок,
второе нажатие останавливает первое. Файл начинает скачиваться лишь после
нажатия, поэтому на скорость сайта отрывки не влияют. Сам по себе звук
не включается никогда — это раздражает людей и штрафуется поисковиками.

### Яндекс.Музыка

Откройте свой альбом или плейлист, нажмите «Поделиться» → «Вставить на сайт»,
скопируйте адрес из кода (он начинается на `https://music.yandex.ru/iframe/…`)
и вставьте вместо `{{ЯНДЕКС_МУЗЫКА_URL}}`.

## 6. Форма заявки

Форма работает через бесплатный сервис Formspree — заявки приходят на почту.

1. Зайдите на formspree.io, зарегистрируйтесь.
2. Создайте новую форму (New Form), укажите почту для заявок.
3. Сервис выдаст адрес вида `https://formspree.io/f/xvgpwkqz`.
4. Скопируйте **последнюю часть** — `xvgpwkqz` — и вставьте вместо
   `{{FORMSPREE_ID}}` в `content.js`, раздел 8.

Пока код не вставлен, форма не отправляется: посетителю показывается
просьба написать в Telegram или позвонить.

Бесплатный тариф — 50 заявок в месяц. Основной путь связи всё равно
кнопки Telegram и WhatsApp, форма — запасной.

## 7. Счётчик Яндекс.Метрики

Метрика показывает, сколько людей заходит на сайт и откуда.

1. Заведите счётчик на metrika.yandex.ru, получите его номер (только цифры).
2. Впишите номер вместо `{{НОМЕР_СЧЁТЧИКА}}` в `content.js`, раздел 11.
3. Откройте `index.html`, найдите в самом низу блок «ЯНДЕКС.МЕТРИКА».
   Удалите строку `<!--` перед ним и строку `-->` после него.
4. В строке с `mc.yandex.ru/watch/НОМЕР_СЧЁТЧИКА` подставьте тот же номер.

Пока блок закомментирован, счётчик не работает и на скорость сайта не влияет.

## 8. Как выложить сайт на хостинг

Сайту не нужен сервер с программами — это обычные файлы.

1. Установите бесплатную программу **FileZilla**.
2. Хостинг пришлёт вам четыре строчки: адрес сервера (host), логин, пароль,
   порт (обычно 21). Введите их вверху окна FileZilla, нажмите «Быстрое соединение».
3. Справа откроется папка сервера. Нужная обычно называется
   `public_html`, `www` или `httpdocs` — зайдите в неё.
4. Слева найдите папку с сайтом и перетащите направо **всё содержимое**:
   `index.html`, `style.css`, `script.js`, `content.js`, `robots.txt`,
   `sitemap.xml`, `.htaccess`, папки `img`, `audio` и `favicon`.

   ⚠️ Файл `.htaccess` начинается с точки, и FileZilla по умолчанию его
   не показывает. Включите «Сервер» → «Принудительно отображать скрытые
   файлы», иначе он не зальётся. Без него сайт работает, просто медленнее.
5. Откройте свой адрес в браузере — сайт на месте.

Когда правите тексты: меняете `content.js` у себя, потом заливаете
только этот один файл поверх старого.

### Почему правки иногда «не видны»

В `.htaccess` прописано, что браузер запоминает картинки и стили надолго —
благодаря этому сайт при повторном заходе открывается почти мгновенно.
Обратная сторона: когда вы замените фото или поправите стили, у себя
вы можете ещё какое-то время видеть старую версию.

Что делать: нажмите `Ctrl+F5` (на Маке `Cmd+Shift+R`) — браузер заберёт
всё заново. У обычных посетителей всё обновится само.

Тексты в `content.js` обновляются быстрее — для них кеш всего один час.

**Проверьте после первой публикации:**

- сайт открывается по адресу с `https://`, а не только `http://`
  (бесплатный сертификат включается в панели хостинга);
- откройте сайт на телефоне и пролистайте до конца;
- отправьте себе ссылку в Telegram — должна показаться картинка и описание;
- добавьте сайт в Яндекс.Вебмастер и Google Search Console,
  укажите там адрес `sitemap.xml`.
